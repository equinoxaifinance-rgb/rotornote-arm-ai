# Benchmarks and evidence gates

RotorNote compares FP32 and INT8 implementations for two real-data workloads.
The primary optimization claim is the materially nonlinear 48→253→126→8
variable-speed head (45,030 MACs per inference). The secondary 48→4 specialist
is only 192 MACs and is disclosed as a micro-workload where runtime overhead is
material.

Both compare:

- FP32 weights with scalar JavaScript dot products;
- row-wise INT8 weights with dynamic INT8 inputs and WebAssembly SIMD dot products.

The benchmark uses feature vectors extracted from the four attributed physical demo recordings. CSV parsing and FFT extraction are excluded because they are identical across engines.

```bash
npm run benchmark -- --output benchmark/results/local-x64-real.json --repetitions 51 --batch 2048 --warmups 16
```

The JSON records raw alternating-order samples, checksums, medians, p95, paired speed ratios, a deterministic 10,000-resample confidence interval, machine identity, and artifact hashes.

## Primary current evidence

`npm run benchmark:anomaly` measures the fitted-unit-pruned 48->253->126->8
network. The production fit starts at 48->256->128->8 and removes five units
that never activate on the complete real-data bank. The eight outputs preserve
the source dataset's observed laboratory conditions; the product collapses
them to healthy versus anomaly.

The deterministic artifact result is 181,668 versus 46,972 learned bytes
(74.1440% reduction), including zero-filled per-row SIMD tail padding. Across
the complete 2,925-signal bank, the engines preserve 100% eight-condition label
agreement with 0.002679 p99 and 0.036721 maximum probability drift. The frozen
native Arm64 run uses 51 alternating-order samples of 1,024 inferences and
measures **1.2737x paired median [1.2718, 1.2749]**. This end-to-end workload is
the Arm optimization headline.

## Secondary specialist evidence

The model artifact reduction is deterministic: FP32 is 784 bytes and INT8 is 208 bytes, a 73.4694% reduction. Across all 2,000 real four-channel recording representations, build-time parity is 100% by production label; p99 probability drift is 2.80e-10 and the disclosed maximum isolated drift is 0.01996.

Current-lineage repeats measure identical linear-head FP32, INT8, and WASM hashes on native Arm64 Neoverse-N2 runners under Node 22.18.0. Each uses 51 alternating-order samples of 2,048 inferences. Paired-median speedups remain in the disclosed **3.2×–3.4× band** and every deterministic bootstrap 95% interval excludes 1.0. All preserve 100% label agreement. Because this network performs only 192 MACs, the band is a secondary runtime micro-benchmark rather than the primary practical-impact claim; each frozen run's JSON remains the source for its exact point and interval.

The separate compiled `vdotq_s32` witnesses matched the scalar result exactly. Their kernel-only ratios are not presented as product throughput. GitHub artifact-zip digests differ per run because the archives include timestamps and run receipts; they are not model hashes. The hashes inside each receipt show that the compared FP32, INT8, and WASM files are identical.

Earlier receipts under `receipts/native-arm64/` belong to superseded model artifacts. They preserve engineering history but are not current product evidence; runs 31693588831, 31693809937, and 31694629861 are the repeatability set for the current optimized artifacts.

## Native Arm gate

The workflow requires `aarch64`, rebuilds generated bytes, runs the full test/validation suite, captures raw benchmark data, and executes the NEON `vdotq_s32` witness against an exact scalar result. A native speed claim is green only when the current commit's paired confidence interval excludes 1. Energy remains unmeasured, so RotorNote makes no energy claim.

## Primary anomaly-head reproduction detail

`npm run benchmark:anomaly` measures the FP32-versus-INT8 boundary for the fitted-unit-pruned 48->253->126->8 network. The production fit starts at 48->256->128->8 and removes five units that never activate on the complete real-data bank, leaving 45,030 multiply-accumulates per inference. The eight outputs preserve the source dataset's eight observed laboratory conditions; the product collapses them to healthy versus anomaly. Its deterministic artifact result is 181,668 versus 46,972 learned bytes (74.1440% reduction), including zero-filled per-row SIMD tail padding, with 100% eight-condition label agreement over the complete 2,925-signal source bank, 0.002679 p99 probability drift, and 0.036721 maximum drift. The frozen native Arm64 run uses 51 alternating-order samples of 1,024 inferences and measures 1.2737× paired median with a [1.2718, 1.2749] deterministic bootstrap 95% interval. A current local x64 diagnostic with 21 alternating-order samples of 64 inferences measures 1.36× [1.26, 1.51]; local timing is supporting evidence only.

The frozen workflow executes the exact pruned head on Arm64 under Node 22.18.0 across 51 alternating-order samples of 1,024 inferences. Its raw JSON, parity, point estimate, bootstrap interval, and artifact hashes are the only native claim. Historical results from the smaller superseded head remain historical and are not transferred to this larger model. Individual GitHub artifact-zip digests may differ because zip metadata differs; the model hashes inside each receipt are authoritative.
